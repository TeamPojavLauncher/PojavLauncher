# Aerix Launcher 2.4.0

A smaller release than 2.3.3, and a happier one: two complaints from playing, and the release itself.

## The FPS counter showed weird text

It was one long message in a pill that sizes itself to its own text. When the counter had no frame
source it printed *"FPS unavailable - no frame source (install the Aerix client mod or use the GLFW
renderer)"* - a full sentence, wider than a phone screen. The view measured that width, drew it past
the edge of the display, and what was left next to the pill's border read as random characters.

What changed:

- Every message the counter can print is short again: `58 FPS (avg. 57)`, `FPS unavailable`,
  `0 FPS - no frames`.
- The pill caps what it draws, so a future message - or a bogus measurement from a counter that
  jumped - cannot draw off the screen or scribble over itself.
- The text is centred instead of left-aligned at the padding edge, which is why it used to ride the
  border. That misalignment was the other half of what read as garbage.
- The full explanation for an unavailable counter is still there, in the view's accessibility
  description, where screen readers reach it and the game screen cannot clip it.

## FPS Counter in the A menu

The A overlay's tile grid now has an **FPS Counter** tile. Tap it to turn the readout on, tap again to
turn it off - mid-game, without leaving for the launcher. It flips exactly the same switch the launch
screen's video options own, so the two can never disagree, and the choice is saved for next time.

It is next to *CPS Counter*, and it is a different thing from the *Performance* tile, which shows the
in-HUD pill with frame timing, battery and RAM.

## Also in this build

- **Layout transparency** (Renderer tab): fade the launcher's cards and panels so the wallpaper reads
  through them. 100% is the design as drawn; it is the card that took the place of the removed Global
  Renderer section.
- **No cape unless you equip one**: an install that had the old default cape saved to its preferences
  has it cleared once, and the 3D preview really erases a cape you take off.

## Installing

Signed with the current key only. If you are on 2.3.3 or newer, this installs over it with your
instances, worlds and settings intact - do not uninstall. If you are still on 2.3.2 or older, install
**2.3.3** first: it is the only build signed with both keys, and it moves you across without losing
anything.
