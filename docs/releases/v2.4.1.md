# Aerix Launcher 2.4.1

A transition release that restores in-place updates over existing 2.3.2 and earlier installations.

## What happened in 2.4.0

Version 2.4.0 was signed with the new clean repository secret key alone, because the planned 2.3.3 transition build had not actually been shipped. As a result, players who had installed Aerix Launcher 2.3.2 or earlier received an Android signature mismatch error (`INSTALL_FAILED_UPDATE_INCOMPATIBLE`) when attempting to update in place.

## The fix in 2.4.1

Aerix Launcher 2.4.1 is double-signed using APK Signature Scheme v2 with **both** the new rotated release key and the retired key:

- If you have 2.3.2 or earlier installed, this update installs directly over it without uninstalling, preserving all your worlds, settings, and accounts.
- If you already clean-installed 2.4.0, this update also installs directly over 2.4.0.
- Once installed, Android registers both keys as trusted signers for Aerix Launcher, enabling seamless updates for future releases.

## Includes everything from 2.4.0

- **FPS counter fix**: No more clipped or garbled text when frame sources are unavailable.
- **FPS Counter in the A menu**: Easily toggle the in-game FPS counter readout directly from the A menu tile grid mid-game.
- **Layout transparency**: Adjust background transparency of launcher cards and panels from the Renderer tab.
- **Default cape cleanup**: Unsaved default capes are cleared, with proper 3D preview removal.
