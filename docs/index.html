The latest game log

What 2.3.3 includes

Every release writes its own log, and this is the current one - the change you can feel first, then the details that make it hold. The full history is in the release notes.

aerix@launcher:~$ release-notes --current v2.3.3
  1. 01 The launcher is its own app now Aerix installs as net.al.aerixlauncher instead of borrowing the upstream package. Your instances, settings and game data are imported on first launch, the old install is left alone as a rollback, and an update can never overwrite the app it copied from.
  2. 02 One memory ceiling, not two The launcher heap and the game heap are budgeted from the same device reading, so a phone that was never able to grant 6 GB stops offering it and says so. Devices that can still take it keep a "Try 6 GB anyway" override.
  3. 03 The A menu stays where you left it Releasing the A button inside the overlay keeps the menu in place. A hide now needs the gesture to start below the system strip and a 240 ms hold, a swipe past the top edge no longer blanks the controls mid-game, and an overlay the launcher did not hide says why on its own pill.
  4. 04 Mouse aim and cursors behave The sensitivity that scales both axes and the per-axis aim sensitivity are separate settings again, cursor skins apply to the overlay, the custom cursor size slider works, and a cursor recorded through the overlay plays back at the size it was drawn at.
  5. 05 Recordings you can find again Clips land in a library you import, share and delete from inside the launcher, with a recents row on Discover - and a take interrupted before it was finalised is kept as -unfinished.mp4 instead of thrown away.
  6. 06 2.3.1: the two crashes players reported A display question asked from the wrong kind of Context was killing the launcher on start on Android 11+, and the runtime dialog crashed while trying to explain a failed install. Both are fixed, and the surface rate read that went with them is guarded.
  7. 07 2.3.2: sorry - the missing Java was ours, not your internet That same crash skipped the two startup lines after it, which were the CPU read and the bundled runtime unpack, so the launcher went looking for a runtime named after no architecture at all and blamed the connection when it could not find one. Startup steps are independent now, the architecture is worked out on demand, an install failure carries the reason behind "Show more", and the crash screen keeps the trace without asking for a permission.
  8. 08 2.3.3: the signing key that should never have been public The warning some security apps raised on install had a real reason - releases were signed with a key committed to this repository, with its password in the file beside it. That key is retired and permanently banned in CI, releases now sign from a secret no clone can read, and 2.3.3 carries both signatures so you can update without uninstalling and losing your worlds.

The stand-out feature

Controls that look like something

Open the control editor and scroll to Control themes. The strip is the artwork itself: tap one and the control wears it, with its own press animation, haptic tick and key sound. Off puts the plain control back, and one button applies the theme you picked to every control in the layout.

Move it freezes the motion if you would rather have a still themed control; Feel it and Hear it switch the haptics and the click. Themes only ever change paint — a key press is still sent on the frame your finger lands, so nothing is delayed.

No first-run wizard, no hidden paywall, no account you have to make for the launcher itself.

Free, and no account to make

Aerix has no sign-up of its own. Bring a Microsoft account, an Ely.by account, or play offline — nothing about you is sent anywhere but the login you chose.

Your data stays on your phone

Instances, worlds, accounts and settings all live in the launcher's own storage. No telemetry, no analytics, no ads.

Updates itself

The in-app updater reads the newest release, picks the build that matches your device, and installs over the old one without touching your data.
